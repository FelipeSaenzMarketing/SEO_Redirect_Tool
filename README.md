Automatic 301 Redirect Generator
A Streamlit web application that automatically generates redirect suggestions between old and new URLs based on text similarity.
Here is How to Use It
Upload a file containing your old URLs (urls_old.csv or .txt).(Only one column with the URLs)
Upload a file containing your new URLs (urls_new.csv or .txt). (Only one column with the URLs)
Adjust the similarity threshold (e.g., 0.6 or 0.7).
Download the generated CSV file with suggested redirects.
📦 Deploy on Streamlit Cloud
Upload this repository to your GitHub account.
Go to https://share.streamlit.io.
Connect your GitHub account and select this project.
In the configuration panel:
Main file: app.py
Branch: main
✅ Done! Your app will run directly in your browser.
🧰 Requirements
Python 3.8 or higher
Streamlit (pip install streamlit)
